# Issue tracker: GitHub

Issues and PRDs live in GitHub Issues for this repository. Use GitHub issue operations to create, read, update, label, comment on, and close issues.

Infer the repository from the `origin` Git remote when operating inside the clone.

## Conventions

- Create an issue for a new specification or ticket.
- Read the issue body, labels, and comments when fetching an existing ticket.
- Apply and remove labels through GitHub issue operations.
- Comment before closing when a durable resolution or decision should be recorded.
- PRs are not treated as a request or triage surface.

When a skill says "publish to the issue tracker", create a GitHub issue.

When a skill says "fetch the relevant ticket", read that GitHub issue and its comments.
